## 如何重新生成 / 抓取其他博主

工具位于仓库 `scripts/weibo/`，登录态已保存在独立浏览器配置中（无需重复登录；
若失效则运行 `wb_login.py` 重新扫码）。

```bash
python scripts/weibo/weibo_report.py "博主昵称" 起始日期
# 例：python scripts/weibo/weibo_report.py "王虎的舰桥" 2026-07-21
# 不填日期默认抓最近 60 天
```

## 注意

- 抓取有风控，脚本会自动限速；博主发帖量大时耗时较长，属正常现象。
- 仅供个人阅读整理，请勿公开传播或商用。
