# 03 · Boss 全图鉴（按章节分类）

> 包含主线全部 Boss 的打法要点。Boss 池在同一章节内随机，标记 ⭐ 为固定 Boss。

---

## 一、第 1 章：地下室 Basement（Cellar / Burning Basement）

| Boss | 打法要点 |
|---|---|
| **Monstro 蒙斯特罗** | 经典跳压+三向弹。保持在它跳起路径的侧面输出，弹幕间隙躲 |
| **Duke of Flies 苍蝇公爵** | 持续召唤苍蝇。优先打本体，苍蝇多时用炸弹清场 |
| **Gemini 双子** | 大怪+小怪捆绑移动。先打小怪（会发射），大怪血厚但好躲 |
| **Steven 史蒂文** | 跳压+小弹幕，体型小、动作快。拉开距离打 |
| **Gish 吉什** | 吐黏液减速弹。中了减速很危险，注意提前走位 |
| **Widow 寡妇** | 吐蜘蛛网困住你+跳压。被网住就尽快按键挣脱 |
| **Larry Jr. 小拉里** | 蠕虫型，分段爬行。站在侧面输出，别堵头 |
| **Famine 饥荒 / Pestilence 瘟疫 / War 战争 / Death 死亡**（四骑士）| 随机出现：饥荒（召唤苍蝇）、瘟疫（毒弹）、战争（骑马冲撞+弹幕）、死亡（镰刀弹+召唤）。掌握弹幕节奏即可 |

## 二、第 2 章：洞穴 Caves（Catacombs / Flooded Caves / Downpour）

| Boss | 打法要点 |
|---|---|
| **Chub 胖墩** | 蠕虫冲撞型，会吐小虫。等它冲过来时绕到侧面打 |
| **Gurdy 葛迪** | 固定不动的巨怪，吐弹+召唤。注意站位角落躲弹幕 |
| **The Haunt 鬼魂** | 先打小幽灵，本体无敌时带"无脸"小怪。清完小怪再输出 |
| **Peep 皮普** | 大眼睛+小眼睛，弹幕密集。绕圈走位，别站弹幕交汇点 |
| **Dingle 丁格** | 分裂怪，越打越小越多。优先集中火力打大块 |
| **Pin 钉子** | 钻地蠕虫，钻出时吐弹。站在地面缝隙侧面，它钻出瞬间躲开 |
| **Mega Maw 巨颚** | 巨型吃人怪，会吞你（吞入造成大量伤害）。保持距离，侧面输出 |
| **Siren 塞壬**（Downpour 固定）| 会**魅惑控制你**（操控反了/朝它走）+ 镜像弹幕。被控制时疯狂按方向键挣脱 |

## 三、第 3 章：墓穴 Depths（Necropolis / Dank Depths / Mines / Ashpit）

| Boss | 打法要点 |
|---|---|
| **⭐ Mom 妈妈**（第 2 小关固定）| 经典妈妈战：踩脚（等脚落下后打脚趾/眼睛）、召唤怪物、眼睛激光。**第一阶段先打脚，第二阶段打眼睛**。移动要快，别贪刀 |
| **Fistula 瘘管** | 分裂血球。越分越小越多，用大范围攻击清 |
| **Teratoma 畸胎瘤** | 召唤飞行怪+分裂。优先打本体 |
| **Mine Lord 矿主**（Mines 固定）| 矿车冲撞+炸药桶。利用炸药桶炸它，注意地形 |
| **Great Gideon 大吉迪恩**（Ashpit 固定）| 巨型石像，丢石柱+地震波。破坏石柱防被砸 |

## 四、第 4 章：子宫 Womb（Utero / Scarred Womb）

| Boss | 打法要点 |
|---|---|
| **⭐ Mom's Heart 妈妈的心脏** | 心脏+血管攻击：心跳弹、血泪喷射、血管冲撞。**打心脏本身**，注意心跳节奏（跳起时弹幕多） |
| **⭐ It Lives 它还活着**（击败 11 次后永久替代）| 妈妈心脏强化版：更快更多弹幕。Boss Rush 也打它 |
| **Cage 牢笼** | 铁笼怪，吐弹+召唤。绕圈打 |
| **Bloat 浮肿** | 大眼睛+弹幕机器。躲在它正下方打（它的弹幕死角） |
| **The Adversary 敌手** | 恶魔型，弹幕+镰刀。侧面输出 |

## 六、第 6 章：终局层

### 宝箱层 Chest / 暗室 Dark Room
| Boss | 打法要点 |
|---|---|
| **⭐ ???（蓝宝宝 Boss）** | 高密度弹幕+泪弹雨。走位要预判，别贪输出 |
| **⭐ The Lamb 羔羊** | 撒旦强化版+传送+更密弹幕。打法同撒旦但要求更高走位 |

### 巨型撒旦 Mega Satan（需 2 把钥匙的隐藏路线）
- **进入方式**：天使房集齐 **2 把"钥匙碎片"**（钥匙碎片 1：天使房雕像后用炸弹；钥匙碎片 2：天使房献祭）→ 暗室/宝箱层的巨型门
- **打法**：超巨型多阶段：第一阶段头部弹幕；第二阶段**天使头+恶魔头**双攻击；第三阶段全屏激光+召唤。输出足够高即可跳过阶段

### ??? 层 / Hush（胎衣）
- **进入方式**：**30 分钟内击败妈妈的心脏/It Lives**，子宫 Boss 房的洞会裂开
- **Hush 打法**：全游戏弹幕密度最高的 Boss 之一：连续弹幕墙+冰弹+激光。**血厚攻高**，需要长距离输出 Build（硫磺火/妈妈的刀）或极强走位

### 虚空 Void / 灾厄 Delirium（胎衣+）
- **进入方式**：击败 Hush 或妈妈后出现虚空门；或巨型撒旦后
- **Delirium 打法**：**会变形为之前的任意 Boss** 并融合攻击！注意它会瞬移+冲锋。推荐高机动 Build。击败后给"完成标记"（各角色全标记必备）

| Boss | 位置 | 打法要点 |
|---|---|---|
| **Siren 塞壬** | Downpour/Dross II | 魅惑控制+镜像，见第 2 章 |

| **⭐ Mother 母体** | Corpse II（尸体层）| **4222 HP 巨兽**：第一阶段上半身固定，手刀投掷+弹幕波+召唤小虫；第二阶段（剩 2222 HP）**头身分离**，全屏滑行+吞噬吸拉+穿屏冲撞。近战/反射她的瘘管球可造成硬直。**全游戏最难 Boss 之一** |

### 尸体层 Corpse 进入方式（打 Mother 的路线）
1. 击败陵墓版妈妈后，Mausoleum II 会开启**血肉之门**
2. 进入方式三选一：
   - 收集 **刀片 1**（Mausoleum 层谜题房）与 **刀片 2**（Mausoleum II 内），合成**刀**（Knife 熟悉物），用它**刺穿血肉之门**
   - 用 1 把钥匙+**爸爸的钥匙**开门
   - 使用特定道具（如 Mr. ME!）开门
3. 穿过血肉之门抵达 **Corpse I → II**，击败 Mother
