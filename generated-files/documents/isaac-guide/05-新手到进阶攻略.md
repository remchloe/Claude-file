# 05 · 新手到进阶攻略

## 一、操作设置

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 方向键/鼠标 | 射击方向 |
| E / 空格 | 主动道具 |
| Q | 卡牌/药丸 |
| 左 Shift | 放下道具 |
| CTRL | 切换角色（Jacob & Esau / Forgotten 灵魂） |
| Tab | 查看道具说明 |
| Ctrl+M | 地图 |

## 二、新手 10 条铁律

1. **先活下来，再谈输出**：血量=容错，恶魔房交易量力而行
2. **每层必清隐藏房**：炸弹永远留 1-2 个给隐藏房
3. **宝箱房道具永远拿**：除非你在刷 D6 重掷
4. **商店优先买**：主动道具、饰品、魂心都值得
5. **药丸谨慎吃**：没解锁"药品鉴定"前，红瓶先别乱吃
6. **Boss Rush 时间**：20 分钟内到第 3 章 Boss 房（新手可无视，后期打标记）
7. **别贪恶魔房**：残血时 2 红心交易=自杀
8. **魂心是好东西**：魂心不占容器上限，等于白送血量
9. **学走位**：大部分 Boss 弹幕有规律，绕圈+间隙穿插
10. **死了就死了**：每次死亡都会解锁新道具进池子，越死越强

## 三、前期目标路线图


## 四、Build（配装）思路

- **伤害流**：高伤害道具（Cricket's Head、Polyphemus）+ 连发 = 秒杀
- **追踪流**：追踪泪（Homing）+ 高射速 = 自动瞄准
- **激光流**：硫磺火/激光类 + 连发 = 全屏覆盖
- **宝宝流**：莉莉丝系 = 军团碾压
- **苟活流**：Holy Mantle + 魂心海 + 回血 = 永不掉血

**核心公式**：伤害 × 射速 × 穿透/追踪 = 输出。任何 Build 都围绕这三项堆。

## 五、进阶技巧

1. **D6 重掷**：以撒的 D6 可以重掷 Boss 房/宝箱房道具，缺什么刷什么
2. **献祭房 12 次**：可以白嫖天使房传送
3. **妈妈的钥匙**：3 层内拿到可以直接开 Mega Satan 门
4. **贪吃模式**：Greed Mode 是刷钱+刷道具的乐园，前期穷困时多打
5. **每日挑战**：Daily Run 固定种子，全球同图，看高手视频学习走位
6. **种子系统**：特定种子可复现（如 R0GUE 等知名种子），练习 Boss 用

## 六、常见死因与对策

| 死因 | 对策 |
|---|---|
| 弹幕密集躲不开 | 放慢节奏，观察规律，走位间隙输出 |
| 恶魔房交易后贫血 | 交易前确认至少剩 2 红心 |
| 诅咒房扣血 | 血多时再进，或用白卡/灵魂卡规避 |
| 隐藏房炸错墙 | 看墙缝/用地图道具，或数邻居房间 |
| 药丸中毒 | 先鉴定再吃（PHD/医生包） |
| 卡关 Boss | 打 Boss 前清完其他房间，堆道具再来 |

## 七、忏悔版新手上手指南

1. **先通一遍背刺线**（哪怕只用 Azazel）：解锁红钥匙和第一个堕化角色
2. **打 Mother 路线**：收集刀片→尸体层→击败母体（解锁 Jacob & Esau）
3. **试试星球馆**：跳 2 个宝箱房后出率大增，道具很强
4. **别怕新敌人**：堕化版敌人只是血厚，攻击模式同普通版
5. **联机合作**：忏悔+支持 4 人合作（本地/在线），和朋友一起开荒很欢乐
