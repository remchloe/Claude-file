## 📌 快速上手

1. 新手首选角色：**阿萨谢尔 Azazel**（自带飞行 + 硫磺火，容错率最高）
2. 目标一：击败**妈妈的心脏** 10 次（解锁蓝宝宝与后续路线）
3. 目标二：击败**撒旦 / 以撒**，解锁更多结局与内容
4. 目标三：完成**背刺线**，击败**野兽 Beast**，见证真结局
5. 进阶：解锁全部 **17 个堕化角色**，完成全角色全标记（Dead God 成就）
