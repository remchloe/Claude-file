# 核心池动态调整体系（Core Pool Dynamic Rebalancing）

> **创建日期**：2026年8月20日
> **更新频率**：每日评估（日报体现）+ 每周审视（周报确认）
> **核心逻辑**：核心池不是静态名单，而是随市场走势动态调整——宽基底仓 + 当前强势主线 + 必要防御。

---

## 一、为什么需要动态核心池

```
静态核心池的问题：
  1. 强势板块不在池中 → 错过主线（如医疗/黄金近期大涨）
  2. 弱势板块占权重 → 拖累组合（如半导体/科创持续下跌）
  3. 路径依赖 → 只看熟悉品种，忽略市场变化

动态核心池的解决：
  1. 用数据发现轮动 → 20日涨幅排名客观识别主线
  2. 资金流向强势 → 权重向市场选择的方向倾斜
  3. 每周期审视 → 适应市场风格切换
```

---

## 二、核心池构成

```
核心池 = 宽基底仓 + 强势主线 + 必要防御
       = 约 7 只 + 现金

结构示例（2026/8/20）：
  进攻主线：医疗20% / 新能源10%
  避险主线：黄金15%
  防御底仓：红利15% / 银行15%
  宽基底仓：沪深300 10%
  港股配置：恒生10%
  现金预留：15%+
```

---

## 三、评估指标与规则

### 3.1 每日评估（日报中体现）

| 指标 | 规则 |
|:----|:-----|
| **20日涨幅** | >3% → 强势，关注配置；<-8% → 弱势，降级回避 |
| **5日动能** | 辅助判断短线变化（强势板块回调 vs 转弱） |
| **量能** | 放量上涨=资金流入；缩量下跌=抛压减弱 |
| **今日涨跌** | 确认短线方向 |

### 3.2 升降级规则

```
升级到核心池（满足其一）：
  - 20日涨幅>3% 且 5日动能为正
  - 连续3日进入全板块排名前3（确认主线）
  - 政策/事件重大催化（允许快速纳入）

降级到观察池（满足其一）：
  - 20日涨幅<-8%（弱势确认）
  - 跌破关键支撑（如箱体下沿/硬止损位）
  - 连续3日进入全板块排名后3

保留但调权重：
  - 宽基底仓：始终保留，权重可调（大盘弱时降低）
  - 防御品种：市场防御期保留，进攻期降低
```

### 3.3 调整频率

```
每日：评估排名+信号，在日报中体现"建议调整"
每周：实际调整核心池配置（周报确认），避免过度交易
季度：全面审视（3/6/9/12月）
触发式：重大政策/事件催生新板块时快速纳入
```

## 七、与三大体系的关系

```
板块轮动跟踪 → 回答"市场主线在哪" → 决定核心池标的
策略风格切换 → 回答"用什么策略" → 决定仓位/网格
核心池动态调整 → 回答"跟踪哪些品种" → 决定SIGNAL信号来源
```

> **核心原则：核心池是市场的镜子，不是用户的偏好。资金流向哪里，核心池就跟到哪里。**
