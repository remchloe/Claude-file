# ETF 策略风格切换体系（Strategy Regime System）

> **创建日期**：2026年8月12日
> **更新频率**：每日研判（日报中体现）+ 风格切换时立即更新
> **核心逻辑**：不同市场风格使用不同策略——趋势市追趋势、震荡市做网格、风险期做防御、切换期做观望

---

## 一、市场风格分类（四大风格）

| 风格 | 代号 | 特征 | 适用策略 |
|:----|:----:|:-----|:--------|
| **单边上涨** | TREND_UP | 指数趋势向上，板块普涨，突破压力位 | 趋势跟踪（追涨+持有） |
| **单边下跌** | TREND_DOWN | 指数趋势向下，板块普跌，跌破支撑位 | 风险规避（现金为王+防御） |
| **震荡市** | RANGE | 箱体震荡，有明确支撑压力，板块轮动快 | 网格交易（高抛低吸） |
| **风格切换期** | SWITCH | 强弱排名快速变化，方向不明 | 观望等待（轻仓+现金+条件单） |

### 1.1 风格识别指标（量化标准）

| 指标 | TREND_UP | TREND_DOWN | RANGE | SWITCH |
|:----|:--------|:----------|:------|:-------|
| 20日趋势 | 站上20日线 | 跌破20日线 | 围绕20日线震荡 | 反复穿越 |
| 板块涨跌比 | >70%上涨 | >70%下跌 | 40~60% | 快速变化 |
| 波动率 | 正常偏高 | 放大 | 正常 | 放大 |
| RSI | 50~70上升 | <40下降 | 40~60 | 背离明显 |
| 量能 | 放量上涨 | 放量下跌 | 缩量震荡 | 量能萎缩 |
| 轮动速度 | 主线清晰 | 避险为主 | 快速轮动 | 无主线 |

## 二、四种风格的完整策略体系

### 2.1 单边上涨（TREND_UP）—— 趋势跟踪策略

```
目标：赚趋势的钱，让利润奔跑

操作规则：
  1. 仓位：70%~90%（重仓）
  2. 标的：强势板块龙头ETF（动量最强的前2~3个）
  3. 买入：突破压力位/回踩20日线企稳时买入
  4. 持有：趋势未破就持有，不轻易止盈
  5. 止盈：跌破10日线减半，跌破20日线清仓
  6. 止损：-8%（单品种）

信号确认：
  - 指数站上20日线且20日线向上
  - 板块涨跌比>70%上涨
  - 连续3日放量上涨
```

### 2.2 单边下跌（TREND_DOWN）—— 风险规避策略

```
目标：保住本金，等待底部信号

操作规则：
  1. 仓位：10%~30%（轻仓）
  2. 标的：仅保留防御（红利/黄金/现金）
  3. 现金：70%以上
  4. 买入：不抄底，等右侧信号（放量止跌+RSI回升）
  5. 止损：任何持仓-5%无条件清仓
  6. 关注：底部信号（放量暴跌后缩量企稳）

信号确认：
  - 指数跌破20日线且20日线向下
  - 板块涨跌比>70%下跌
  - 连续3日放量下跌
```

### 2.3 震荡市（RANGE）—— 网格交易策略

```
目标：赚震荡的钱，高抛低吸

操作规则：
  1. 仓位：40%~60%（网格资金+底仓）
  2. 网格资金：总资金40%（分5格）
  3. 网格区间：箱体上下沿加缓冲
  4. 每格间距：4%~5%
  5. 每格金额：网格资金/5
  6. 止损：跌破区间下沿清仓（生命线）
  7. 止盈：触及上沿考虑全出，等回踩再开新网格

信号确认：
  - 指数围绕20日线震荡（反复穿越）
  - 板块涨跌比40~60%
  - 有明确支撑位和压力位（箱体）
  - 缩量震荡
```

### 2.4 风格切换期（SWITCH）—— 观望等待策略

```
目标：不亏钱，等待新风格确认

操作规则：
  1. 仓位：20%~40%（轻仓）
  2. 现金：60%以上
  3. 条件单：挂好回踩/突破条件单，自动捕捉方向
  4. 不主动：不做方向性判断，不追涨不抄底
  5. 切换确认：连续3日满足新风格指标后，切换到对应策略

信号确认：
  - 强弱排名快速变化，无持续主线
  - 量能萎缩，观望情绪浓
  - 关键位置反复争夺（支撑/压力均未有效突破）
```

## 三、风格切换机制

### 3.1 切换触发条件（量化标准）

| 当前风格 | 切换目标 | 触发条件 |
|:--------|:--------|:--------|
| RANGE | TREND_UP | 放量突破箱体上沿+连续3日站稳 |
| RANGE | TREND_DOWN | 放量跌破箱体下沿+连续3日无法收回 |
| TREND_UP | RANGE | 突破后回落到箱体内+量能萎缩 |
| TREND_UP | SWITCH | 高位放量滞涨+强弱排名混乱 |
| TREND_DOWN | RANGE | 缩量企稳+箱体形成 |
| TREND_DOWN | SWITCH | 底部信号出现但未确认 |
| SWITCH | 任一 | 连续3日满足新风格指标 |

### 3.2 风格切换执行流程

```
Step 1: 识别切换信号（每日日报轮动研判部分标注）
Step 2: 确认（连续3日满足指标 = 确认切换）
Step 3: 切换执行（按新风格策略调整仓位和标的）
Step 4: 记录切换（月报中记录切换时间点和原因）
Step 5: 复盘验证（切换后验证是否正确）
```

### 3.3 切换注意事项

```
1. 切换需要连续3日确认，避免被单日假信号骗
2. 切换时先减后加——先减旧仓位，再建新仓位
3. 切换初期可混合策略（如RANGE转TREND_UP时，网格继续跑+新增趋势仓）
4. 重大事件（政策/地缘/数据）可能加速切换，允许快速切换（1日确认）
```

## 五、与现有体系的融合

### 5.1 三层体系架构

```
第一层：宏观判断（月报/周报）
  -> 确定大方向（8月：A股科技>防御>港股）

第二层：风格判定（每日）

  -> 网格参数/趋势仓位/条件单设置
```

| 体系 | 回答的问题 | 输出 |

**三者配合：轮动决定方向，风格决定打法，框架决定工具。**
