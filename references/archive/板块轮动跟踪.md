### 1.2 每日板块相对强弱排名表（新增核心机制）

> **核心原则：用数据发现轮动，而不是靠主观关注。**

每日日报必须输出以下排名表：

| 排名 | 板块 | 代码 | 5日涨幅 | 20日涨幅 | 信号 |
|:----:|:----|:----:|:------:|:-------:|:----|
| 1 | 新能源 | 516160 | ... | ... | 强势 |
| 2 | 医疗 | 512170 | ... | ... | 强势 |
| ... | ... | ... | ... | ... | ... |
| 末位 | 芯片 | 159995 | ... | ... | 弱势 |

排名规则：
  1. 覆盖核心池全部14只（含新能源/医疗/券商/军工/芯片）
  2. 按20日涨幅排序（中长期趋势），5日涨幅辅助（短线变化）
  3. 20日涨幅>3% → 标记"强势"，关注配置机会
  4. 20日涨幅<-8% → 标记"弱势"，等待企稳或回避
  5. 排名连续3日变化>3位 → 标记"轮动加速"，重点分析

轮动预警信号：
  - 某板块连续3日进入前3 → 提示"新主线出现"
  - 某板块连续3日进入后3 → 提示"资金流出"
  - 某板块从弱势转强势（20日从<-8%转>3%）→ 提示"趋势反转"

### 1.3 轮动方向判断指标

| 指标 | 说明 | 触发信号 |
|:----|:-----|:--------|
| **相对强弱** | 各板块20日相对收益排名 | 排名变化=轮动方向 |
| **RSI背离** | 板块RSI vs 价格走势 | RSI高但价格滞涨=轮出信号 |
| **量能变化** | 板块成交额vs 5日均量 | 放量上涨=轮入，放量下跌=轮出 |
| **资金流向** | 北向/南向/ETF份额变化 | 持续流入=资金选择方向 |
| **政策催化** | 产业政策/监管变化 | 新政策=新轮动起点 |
| **全球联动** | 美股/费城/港股传导 | 全球风格切换先行指标 |

## 二、轮动跟踪方法（每日）

### 2.1 每日轮动检查清单

```
每日日报必须包含的轮动研判：

1. 今日各板块相对强弱排名（谁强谁弱）
2. 轮动方向判断：当前处于哪个风格周期
   - 进攻期（科技领涨）
   - 防御期（银行/红利领涨）
   - 切换期（从防御转向进攻或反之）
   - 均衡期（无明确主线）
3. 信号变化：哪些信号在强化/弱化
4. 操作含义：结合当前仓位给出轮动建议
```

### 2.2 轮动周期判定标准

| 周期 | 特征 | 操作策略 |
|:----|:-----|:--------|
| **进攻期** | 科技连续3日以上跑赢防御，量能放大 | 重仓科技成长，减防御 |
| **防御期** | 银行/红利连续跑赢科技，避险情绪 | 重仓防御，轻科技 |
| **切换期** | 强弱排名快速变化，方向不明 | 均衡配置，提高现金 |
| **均衡期** | 各板块涨跌接近，无明确主线 | 持有底仓，等方向 |
