## 二、日报核心框架（三维度）

> **2026/9/15 升级**：从"纯技术面"升级为"三维度"，补齐宏观与事件维度。

```
第一维：宏观环境（新增）
  · 隔夜外盘：费城半导体/纳指/道指（尤其费半 vs A股半导体的联动/背离）
  · 汇率/流动性：人民币中间价、央行公开市场操作、两融余额
  · 今日经济数据与政策：统计局发布、部委政策、央行操作
  · 经济周期定位：复苏/过热/滞胀/衰退 → 对应板块（etf-analysis 4.2）

第二维：资金与事件（新增）
  · 资金流向：主力资金（加仓/减仓板块）、北向/南向
  · 板块催化剂：政策/产业事件
  · 抽血预警：重大IPO（>50亿）上市前5日
  · 地缘政治

第三维：技术面（保留）
  · 板块动量：20日涨幅排序（etf-analysis 行业轮动法）
  · 反弹质量：量能验证（今日量/前日量比）
  · 重点品种：RSI / 均线 / 支撑压力
  · 组合配置：核心-卫星（etf-analysis 4.1）
  · 操作建议：信号 + 价格区间 + 失效条件 + 条件单
```

### 日报完整结构

```
〇、昨日验证回顾
```

### 为什么要有宏观维度

> 详见 2026/9/15 实例：若只看技术面，当日是"放量反弹"的积极信号；
> 补上宏观后才发现——**外盘费城半导体暴跌-5.86%、两融连续下降**，反弹缺乏外部环境支撑，
> 仅靠国内政策（集成电路全链条攻关）独撑。
> **三维框架避免把"政策性反弹"误读为"趋势反转"。**

## 三、核心方法论（从 etf-analysis 提炼）

### 1. 行业轮动动量法（2026/9/24 升级：动量结构分析）

> **原方法缺陷**：只看20日涨幅排序 → 会被"历史残留的强势"误导（滞后指标）。
> **升级**：增加**动量结构判定**——用 5日/10日/20日 的排列关系判断动能方向。

```
【动量结构四型】

🔥 加速型（真强势）：5日 > 10日 > 20日，且均为正
   → 动能持续增强，可信度最高

🟡 放缓型：5日 < 10日，但均为正
   → 涨速减慢，需警惕动能见顶

⚠️ 衰减型（假强势）：10日为负，20日为正
   → 20日涨幅来自历史，近10日实际在跌，绝不可标"最强"

🟢 反转型：20日为负，5日/10日转正
   → 由弱转强，需确认持续性
```

```
【关键规则（防止误判）】
① 衰减型板块即使20日排名第一，也不得标记"最强主线"
② 筛选"强势"必须同时满足：近期动能(5/10日)为正 + 有催化或资金验证
③ 无新闻催化的板块，必须明确标注"纯资金驱动，注意持续性"
④ 日报中同时呈现"20日排名"和"动量结构"，两者冲突时以结构为准
```

**实例（9/23）**：
| 板块 | 5日 | 10日 | 20日 | 20日排名 | 结构判定 |
|:----|:---:|:---:|:---:|:---:|:-----|
| 军工 | 0.00% | **-2.54%** | +4.45% | 第1 | ⚠️ **衰减型**（假强势） |
| 半导体 | +4.27% | +6.92% | +3.34% | 第2 | 🟡 放缓型 |
| 医疗 | +4.18% | +3.56% | +1.16% | 第5 | 🔥 **加速型**（真强势） |

> **结论**：军工20日排第一但实为衰减（近10日-2.54%）；医疗20日仅第5但为真加速。
> **排序不代表强势，结构才代表。**

### 2. 核心-卫星配置
```
核心仓（70~80%）：宽基/防御，获取beta，低换手
卫星仓（20~30%）：行业ETF，右侧信号参与，允许高换手
```

### 3. 技术面辅助
```
RSI(14)：<30超卖 / >70超买 / 50为强弱分界
MA20：中期趋势线（站上=多头，跌破=空头）
MA60：牛熊分界
量能验证：今日量/前日量（半日量比>85%=放量，<60%=缩量）
```

## 四、实战纪律（从 etf-operation 提炼）

```
① 每个信号带失效条件（收盘跌破X则失效）
② 每个买卖信号带具体价格区间
③ 核心判断带情景概率
④ 不猜底、不追高——右侧信号确认再参与
⑤ 周五降低进攻信号，提高现金2~5%
⑥ 突破/反弹需量能验证（无量突破不可靠）
⑦ 宏观背离必查（如外盘与A股同板块背离 → 判断驱动来源）
```
