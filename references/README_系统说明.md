```
一、市场环境定位      → 阶段判断（趋势/震荡/切换）+ 本周主要矛盾
```

## 三、核心方法论（从 etf-analysis 提炼）

### 1. 行业轮动动量法
```
用20日涨幅排序识别中期主线，今日涨幅辅助判断短线变化
关键：区分中期趋势 vs 短线反弹（均线方向是最佳过滤器）
```

### 2. 核心-卫星配置
```
核心仓（70~80%）：宽基/防御，获取beta，低换手
卫星仓（20~30%）：行业ETF，右侧信号参与，允许高换手
```

### 3. 技术面辅助
```
RSI(14)：<30超卖 / >70超买 / 50为强弱分界
MA20：中期趋势线（站上=多头，跌破=空头）
MA60：牛熊分界
```

## 四、实战纪律（从 etf-operation 提炼）

```
① 每个信号带失效条件（收盘跌破X则失效）
② 每个买卖信号带具体价格区间
③ 核心判断带情景概率
④ 不猜底、不追高——右侧信号确认再参与
⑤ 周五降低进攻信号，提高现金2~5%
```
